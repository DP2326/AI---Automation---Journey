# Day 2 — AI Fundamentals

## Topics Learned

### 1. LLM
LLM is the AI brain that understands and generates text.

Example:
Customer asks a question → LLM understands it and creates a reply.

### 2. Tokens
Tokens are small pieces of text that AI processes.

Example:
"I want a phone" → AI processes the text as tokens.

### 3. Context
Context is the information given to AI to understand the situation.

Example:
Product = Blue Shoes
Price = ₹2,000

Customer: "What is the price?"
AI: "The blue shoes cost ₹2,000."

### 4. Prompt
A prompt is the instruction given to AI.

Example:
"Reply politely to this customer in 2 sentences."

### 5. Hallucination
A hallucination happens when AI gives information that is not supported by the available information.

Example:
AI doesn't know the shoe price but says the price is ₹2,000.

### 6. Structured Output
Structured output means asking AI to return information in an organized format.

Example:

{
  "product": "blue shoes",
  "size": "9"
}

## Key Learning

LLM = AI Brain
Tokens = Text Pieces
Context = Background Information
Prompt = Instruction
Hallucination = Made-up Information
Structured Output = Organized Data
